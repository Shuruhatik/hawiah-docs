# Hawiah Core Documentation

> **The Ultimate Universal Driver & Hybrid ORM**

**Hawiah** is a powerful, universal database abstraction layer designed to make switching between databases effortless. It provides a consistent API across SQL, NoSQL, In-Memory, and File-based storage systems, now enhanced with a revolutionary **Hybrid Schema** engine and **Virtual Relationships**.

## Core Philosophy
**"Write Once, Run Anywhere."**

Traditionally, ORMs are tied to SQL (like TypeORM) or NoSQL (like Mongoose). Switching from MongoDB to PostgreSQL usually means rewriting your entire data layer. 

**Hawiah solves this.**
- **Unified Interface:** `insert`, `get`, `update`, `delete` work exactly the same on Redis, MySQL, or a local JSON file.
- **Hybrid Storage:** Intelligent storage mapping. It uses tables for SQL and documents for NoSQL, without you changing a line of code.
- **Zero Lock-in:** Start your project with a simple JSON file driver, and switch to PostgreSQL in production by changing just 2 lines of config.

## Summary

Hawiah gives you:
1.  **Universal API** across all DBs.
2.  **Hybrid Schema Power** (SQL tables + JSON flexibility).
3.  **Modern Relationships** (Virtual, Cross-DB, High Performance).
4.  **Zero Lock-in**.

**Simple enough for a prototype, powerful enough for enterprise.** 🚀

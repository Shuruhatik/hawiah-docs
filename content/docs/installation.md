# Installation

Get started with Hawiah by installing it via your preferred package manager.

## NPM

```bash
npm install hawiah
```

## Yarn

```bash
yarn add hawiah
```

## PNPM

```bash
pnpm add hawiah
```

## Requirements

- Node.js 14.x or higher
- A supported database driver (MongoDB, MySQL, PostgreSQL, SQLite, etc.)

## Next Steps

After installation, check out the [Quick Start](#quick-start) guide to begin using Hawiah in your project.
